### 版本变更详情
#### ✨ 新功能
    - 新增自动计划配置统一 JSON 字段，支持数据兼容性迁移，更新 MySQL、PostgreSQL、SQLite 表结构
    - 新增枚举工具类 `EnumUtils`，支持通过私有字段查找枚举实例与获取所有枚举值
    - Boss 任务配置新增任务执行超时时间字段，默认 240 秒
    - 新增 API 签名模块 IP 白名单与黑名单配置，前端 API 调用统一为 `ApiService`，接口路径统一 `/api` 前缀

#### 🐛 修复
    - 修复数据备份恢复时自动计划配置字段映射问题，补充 camelCase 格式字段的获取与移除逻辑，确保数据完整性

#### 🔧 改进与重构
    - 重构自动计划领域模型：将 `AutoFight` 重命名为 `AutoDomain`，更新前后端全部引用，标记废弃字段并修正 `AutoPlanType` 枚举（`SECRET` → `STYGIAN_ONSLAUGHT`）
#### ✨ 上游 v0.1.9 功能
    - UID队伍信息管理增加批量删除功能，表格支持多选框、批量删除按钮
    - 新增`ClassConvert`通用对象转换注册中心，统一实体VO/DTO转换逻辑，支持单向/双向转换器、组合键注册
    - 新增`Valid`校验注册中心，支持组合键校验器注册、重复注册检测、完整异常抛出
    - 新增`IServicePlus`增强MyBatis‑Plus服务接口，内置`lambdaQueryWrapper`/`lambdaUpdateWrapper`简化条件构造
    - UID映射、队伍信息、WS代理管理页面全部改为分页表格组件，支持分页参数、搜索筛选
    - WS‑代理模块重构，新增分页查询接口，前端Element‑Plus表格重构，移动端响应式适配
    - 新增UID队伍配置完整CRUD能力，数据表`uid_team_config`，支持备份恢复、UID+type唯一性校验
    - 新增任务抽象`Task`与`ThreadUtil`多线程工具，支持阻塞等待、异步回调、超时控制、任务异常捕获
    - 应用启动安全基线检查`SecurityWarnRunner`，检测默认弱口令、JWT默认密钥、未鉴权开放接口并输出告警
    - WebSocket客户端关闭增加异常捕获，避免session关闭异常导致程序崩溃
    - 游戏资源数据更新：新增荒坠的圣迹、妄念的创痕、山风的荆冕、逆悬的冰河；国家列表增加至冬国
